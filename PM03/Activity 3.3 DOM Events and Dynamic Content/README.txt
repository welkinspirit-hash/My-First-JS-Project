# Dynamic Shopping List & Live API Profile

A lightweight, high-performance web interface built as evidence for the redAcademy Career Accelerator course curriculum framework. This utility web application combines dynamic item monitoring logic with external live web server payload fetching pipelines.

## Purpose of the Project
* Provide dynamic UI list structures allowing user manipulation
* Offer interface display theme toggles for accessible view states
* Execute secure client-server connections tracking profile data objects
* Intercept and manage unexpected internet server error drops safely

## File Layout Matrix
* index.html: Holds the application layouts, structural containers, interactive event click buttons, and text fields.
* style.css: Coordinates visual alignment, padding spacing blocks, status styling modules, and dark layout themes.
* app.js: Operates form inputs, runs DOM element creation trees, and runs async/await network routines.

## JavaScript Logic Mechanisms Implemented
* DOM Controls: document.getElementById(), document.querySelector(), appendChild(), removeChild()
* Runtime Listeners: Form submit event parsing, button click triggers
* Pipeline Protection: event.preventDefault() block mechanisms
* Data Streams: fetch() API operations backed by try...catch lifecycle handlers
