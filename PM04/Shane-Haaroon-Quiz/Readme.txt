# CyberAware Quiz
## Overview

CyberAware Challenge is a gamified cybersecurity awareness platform designed to improve employee security knowledge through an interactive quiz,
The platform helps teams become more cybersecurity aware, measure employee knowledge, and identify training opportunities.

---

## Features

- User login
- Cybersecurity quiz
- Real-time scoring
- Gamification and badges
- User dashboards
